**РУССКИЙ**

**Описание**
No-ZIP - это простая и гибкая утилита для распаковки файлов с поддержкой различных алгоритмов архивации. Программа построена по модульной архитектуре, что позволяет легко добавлять новые форматы сжатия.

Возможности
- Модульность: Поддержка различных алгоритмов через модули
- Простота: Минималистичный и понятный интерфейс 
- Гибкость: Возможность расширения функционала без изменения основной логики

Поддерживаемые форматы
- ZIP (базовый)


**ENGLISH**

**Description**
No-ZIP is a simple and flexible utility for unpacking files with support for various archiving algorithms. The program is built on a modular architecture, allowing new compression formats to be easily added.

Features

- Modularity: Support for various algorithms via modules
- Simplicity: Minimalistic and user-friendly interface
- Flexibility: Ability to expand functionality without changing the core logic

Supported Formats
- ZIP (basic)
