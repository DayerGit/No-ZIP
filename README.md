# No‑ZIP

**No‑ZIP** - это простая и гибкая утилита для распаковки файлов, поддерживающая различные алгоритмы архивации. Проект написан на **C++** и построен по модульной архитектуре, что позволяет легко добавлять новые форматы сжатия без изменения основной логики.

---

## Возможности

- **Модульность** - поддержка различных алгоритмов через подключаемые модули.
- **Простота** - минималистичный и понятный интерфейс.
- **Гибкость** - возможность расширения функционала без изменения ядра программы.

---

## Поддерживаемые форматы

- **ZIP** (базовый)

---

## Архитектура

Проект разделён на две основные части: **ядро** (общая логика распаковки) и **модули** (реализации конкретных форматов).

### Ядро

- **Модульный загрузчик** - динамическое подключение модулей распаковки.
- **Универсальный интерфейс** - единый API для работы с любым поддерживаемым форматом.

### Модули

- **ZIP** - базовая реализация распаковщика для формата ZIP.
